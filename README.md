# ⭐ نجومي — منصة تعلّم عربية للأطفال

منصة تعليمية تفاعلية بالعربية للأطفال (٤–٩ سنوات)، مستوحاة من تصميم **Kidzio**
ومبنيّة بالكامل بـ HTML و CSS و JavaScript خالص — **بدون أي إطار عمل، وبدون خطوة بناء، وبدون خادم**.

افتح `index.html` في المتصفّح وستعمل المنصّة فورًا.

---

## ✨ ما الذي يعمل فعليًا؟

كل زرّ في المنصّة قابل للضغط ويؤدي وظيفته الحقيقية. لا توجد شاشات وهمية.

### الصفحات

| الصفحة | الملف | الوصف |
|---|---|---|
| الرئيسية | `index.html` | مهمّة اليوم، السلسلة، خطة اليوم، المواد، الألعاب، الأصدقاء، الأوسمة |
| استكشف وتعلّم | `learn.html` | كل المواد مع **فلاتر تعمل** (تصنيف · مستوى · حالة) وبحث نصّي |
| صفحة المادة | `subject.html?s=math` | قائمة دروس المادة ونسبة التقدّم |
| مشغّل الدرس | `lesson.html?s=math&l=m1` | بطاقات شرح ثم ٤ أسئلة تدريب ثم شاشة إنجاز |
| اختبار سريع | `quiz.html` | ١٠ أسئلة · ٣ قلوب · مؤقّت ٢٠ ثانية · مكافأة سرعة وتتابع |
| عدّ واحسب | `game-counting.html` | مسائل مولَّدة عشوائيًا بثلاث درجات صعوبة + لوحة أرقام |
| لعبة الذاكرة | `game-memory.html` | ٨ أزواج بأربع مجموعات · مؤقّت وعدّاد أخطاء |
| كوّن الكلمة | `game-word.html` | رتّب الحروف المبعثرة لتكوين ١٦ كلمة عربية |
| الجوائز | `rewards.html` | المستوى، هديّة يومية، إحصاءات، ١٠ أوسمة |
| الترتيب | `leaderboard.html` | منصّة تتويج وجدول ترتيب يضمّك بين الأصدقاء |
| ملفّي | `profile.html` | تعديل الاسم والصورة، تقدّم المواد، الإعدادات |

### الآليات

- **نقاط الخبرة والمستويات** — كل ٢٠٠ نقطة = مستوى جديد، مع احتفال عند الترقية.
- **الدوريات** — برونزي → فضّي → ذهبي → ماسي حسب مجموع النقاط.
- **السلسلة اليومية** — تُحتسب تلقائيًا من أيام النشاط، وتظهر في شريط الأسبوع.
- **مهمّة اليوم** — ٣ أنشطة يوميًا، يتحدّث شريط التقدّم بعد كل درس أو لعبة.
- **١٠ أوسمة** تُفتح بشروط حقيقية (٣ دروس، ٢٠ إجابة صحيحة في الحساب، علامة كاملة…).
- **هديّة يومية** — تُفتح مرة كل يوم وتمنح نقاطًا عشوائية.
- **أصوات** مولّدة بـ Web Audio (لا ملفات صوتية) — إجابة صحيحة/خاطئة/فوز.
- **قصاصات احتفال** عند الفوز وفتح الأوسمة.
- **وضع ليلي** كامل يُحفظ بين الجلسات، مع منع وميض الشاشة عند التحميل.
- **تبديل الأرقام** بين ١٢٣ و 123 من الإعدادات.

كل التقدّم يُحفظ في `localStorage` تحت المفتاح `nujoomi.v1` — لا خادم ولا حساب ولا إرسال بيانات.

## 🎨 التصميم

- **الخطوط**: `Baloo Bhaijaan 2` للعناوين + `Tajawal` للنصوص (نظيرا خطّي Kidzio بالعربية).
- **الألوان**: نفس لوحة Kidzio — بنفسجي `#7C5CFF`، نعناعي `#4ED6A8`، سماوي `#49B8FF`،
  شمسي `#FFB547`، مرجاني `#FF7A8A`، وردي `#FF8FC5`، على خلفية `#FFF8F1`.
- **RTL أصلي** — الاتجاه من اليمين لليسار في كل مكان عبر خصائص `inset-inline` و `margin-inline`.
- **إطار موبايل** بعرض ٤٤٠ بكسل يتوسّط الشاشة على سطح المكتب.
- كل الأيقونات **إيموجي** — لا مكتبة أيقونات ولا صور، تعمل بلا إنترنت (عدا الخطوط).

## ✏️ كيف تعدّل المحتوى؟

كل النصوص التعليمية في ملف واحد: **`assets/js/data.js`**.

**إضافة سؤال** إلى بنك موجود:

```js
QUESTIONS.animals.push({
  q:'أيّ حيوان ينام في الشتاء؟',
  o:['دبّ 🐻','قطة 🐱','بقرة 🐄','ديك 🐓'],
  a:0,                              // رقم الخيار الصحيح (يبدأ من ٠)
  h:'الدبّ يدخل في بيات شتوي.'      // تلميح يظهر بعد الإجابة
});
```
الخيارات تُخلط تلقائيًا في كل مرة، فلا داعي لترتيبها.

**إضافة درس** إلى مادة:

```js
LESSONS.math.push({
  id:'m5', title:'الأعداد الزوجية', emoji:'2️⃣', mins:4,
  teach:[ { t:'ما العدد الزوجي؟', b:'العدد الذي يُقسم على ٢ بلا باقٍ.', e:'2️⃣' } ],
  bank:'count'                      // من أي بنك تُسحب أسئلة التدريب
});
```

**إضافة مادة جديدة**: أضف عنصرًا إلى `SUBJECTS`، ثم `LESSONS.<id> = [...]`،
ثم بنك أسئلة في `QUESTIONS`. الصفحات كلها تلتقط الإضافة تلقائيًا.

**إضافة كلمة** للعبة التكوين: `WORD_GAME.push({ w:'سحاب', e:'☁️', hint:'يحمل المطر' });`

## ▶️ التشغيل والنشر

**محليًا** — افتح `index.html` مباشرة، أو شغّل خادمًا بسيطًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

**النشر** — الموقع ملفات ثابتة فقط، فيصلح لأي استضافة:

- **Vercel**: `vercel --prod` من مجلد المشروع (لا حاجة لأي إعداد).
- **GitHub Pages**: فعّلها من إعدادات المستودع واختر الفرع.
- **Netlify**: اسحب المجلد وأفلته.

## 📌 ملاحظات

- الأصدقاء في صفحة الترتيب بيانات تجريبية للعرض فقط — لا يوجد خادم أو تواصل بين المستخدمين.
- المنصّة مهيّأة كـ PWA بملف `manifest.json` (أيقونة واسم وألوان)، لكن بلا Service Worker
  حتى تبقى بسيطة وسهلة التحديث. أضِف واحدًا لاحقًا إذا احتجت العمل دون إنترنت.
