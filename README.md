# منصة غرس (Ghars) — منصة القيم الأسرية

> **اسم مؤقت قابل للتغيير** — انظر `docs/OWNER_DECISIONS.md` (قرار جوهري معلّق).

منصة رقمية أسرية تساعد **ولي الأمر** على تحويل القيم التربوية إلى **أهداف ومهام عملية**
قابلة للمتابعة داخل الأسرة، مع تحفيز الأبناء عبر **تلعيب آمن (Gamification)**.

## النموذج الجوهري

```
القيمة → الهدف → المهمة → التنفيذ → الاعتماد → القياس → التلعيب → التقارير
```

التلعيب طبقة تحفيزية فوق جوهر تربوي وسلوكي — وليس هو الجوهر.

## القيم الأربع المعتمدة (المرحلة الحالية)

| القيمة | القيم الفرعية |
|--------|----------------|
| الاحترام | الأدب، التقدير، التواضع |
| التعاون | البذل، الإيثار، الكرم |
| الاهتمام | الحرص، تنفيذ المهام |
| الالتزام | التنظيم، الوفاء، الصدق |

## القاعدة الذهبية للمشروع

**لا تُبنى قرارات جوهرية على افتراضات غير مؤكدة.** عند نقص معلومة تؤثر على توجّه
المشروع، يُرجع لصاحب المشروع قبل اتخاذ القرار. القرارات الجوهرية المعلّقة موثّقة في
`docs/OWNER_DECISIONS.md`، والقرارات الصغيرة التقنية تُنفّذ مؤقتًا مع وسم `TODO`.

## الهيكل

```
.
├── apps/
│   ├── web/        تطبيق ولي الأمر والابن (Next.js + TypeScript)
│   └── admin/      لوحة إدارة المحتوى والنظام
├── packages/
│   ├── ui/         مكونات واجهة مشتركة (Tailwind)
│   ├── config/     إعدادات مشتركة (tsconfig, eslint, ...)
│   ├── gamification/  منطق التلعيب (XP, levels, badges)
│   └── database/   أنواع وعميل قاعدة البيانات
├── supabase/
│   ├── migrations/ مخطط قاعدة البيانات (SQL)
│   └── seed/       بيانات أولية (القيم، المستويات، الشارات)
└── docs/           وثائق المشروع المرجعية
```

## التقنية المقترحة (لـ MVP — تحتاج اعتماد نهائي)

- **Frontend:** Next.js + TypeScript
- **Backend/Database:** Supabase + PostgreSQL
- **Auth:** Supabase Auth (دخول ولي الأمر/الطاقم؛ دخول الابن تابع لحساب ولي الأمر)
- **UI:** Tailwind CSS
- **Repo:** GitHub · **PM:** GitHub Projects

## ترتيب التنفيذ

1. تثبيت النموذج والتوثيق ✅
2. بناء نموذج البيانات + RLS ✅ (`supabase/migrations`)
3. تجربة ولي الأمر ✅ (`apps/web`)
4. تجربة الابن + اعتماد ولي الأمر ✅
5. التلعيب الآمن (XP، مستويات، شارات، إنجازات، صناديق مكافآت) ✅
6. التقارير (الابن/الأسرة/مؤشرات عامة) ✅
7. العرض الاستثماري + ترتيب الأسر (مجهول الهوية) ✅

> **النسخة الأولى (MVP) مكتملة.** المسار الكامل يعمل من اختيار القيمة حتى التقارير والترتيب.
