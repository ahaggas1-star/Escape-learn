# نطاق الـMVP — MVP_SCOPE

## الهدف من الـMVP

إثبات الفكرة الأساسية، وليس بناء كل شيء دفعة واحدة. يجب أن يُثبت الـMVP أن ولي الأمر
يستطيع: اختيار قيمة → ربطها بهدف → تحويلها إلى مهام → متابعة تنفيذها → وأن الابن
يتفاعل مع التجربة من خلال التلعيب.

## 14.1 داخل نطاق الـMVP

- [ ] تسجيل ولي الأمر
- [ ] إنشاء أسرة
- [ ] إضافة الأبناء
- [ ] عرض القيم الأربع
- [ ] اختيار قيمة
- [ ] عرض أهداف جاهزة
- [ ] إنشاء هدف خاص
- [ ] إسناد مهام
- [ ] إكمال مهمة من الابن أو عبر ولي الأمر
- [ ] اعتماد ولي الأمر
- [ ] XP
- [ ] شريط تقدم
- [ ] شارات بسيطة
- [ ] صناديق مكافآت مبسّطة
- [ ] تقرير أساسي للابن
- [ ] تقرير أساسي للأسرة
- [ ] لوحة إدارة بسيطة للمحتوى
- [ ] لوحة مؤشرات عامة للتجربة

## 14.2 خارج نطاق الـMVP

لا يدخل في النسخة الأولى إلا إذا قرر صاحب المشروع خلاف ذلك:

- تطبيق جوال أصلي iOS/Android
- ذكاء اصطناعي لتوليد الأهداف
- ترتيب عام بين جميع الأطفال
- متجر مكافآت تجاري
- دفع إلكتروني
- مجتمع مفتوح
- محادثات بين الأطفال
- نشر إنجازات اجتماعي
- تكاملات خارجية
- محتوى ضخم لكل الأعمار
- نظام مدارس أو مؤسسات كامل

## 14.3 تجربة المستثمر (مسار العرض)

يجب أن تعرض نسخة الـMVP المسار التالي بشكل كامل وسلس:

1. ولي الأمر يدخل
2. ينشئ أسرة
3. يضيف ابنًا
4. يختار قيمة: الالتزام
5. يختار هدفًا جاهزًا: تنظيم المهام اليومية
6. يسند مهامًا للابن
7. الابن ينجز المهمة
8. ولي الأمر يعتمد الإنجاز
9. يظهر XP وشريط التقدم
10. يفتح صندوق مكافأة
11. يظهر تقرير يوضح التقدم

هذا المسار كافٍ لإظهار قيمة المنصة للمستثمر في العرض الأول.
