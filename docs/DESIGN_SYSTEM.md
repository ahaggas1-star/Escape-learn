# نظام التصميم — قِيَم

هوية **نظيفة عصرية احترافية** بإحساس المنصات الحكومية السعودية (Tawakkalna/Absher/Nafath):
خلفيات بيضاء، لون أساسي مهيب، حدود رقيقة، خطوط واضحة، وسهولة تمييز ووصول لولي الأمر والطفل.
المرجع التقني: `apps/web/tailwind.config.ts` و`apps/web/app/globals.css`.

## المبادئ

- **نظافة ووضوح:** أسطح بيضاء، مساحات بيضاء سخيّة، حدود رقيقة (`line`)، ظلال خفيفة جدًا.
- **تمييز سهل:** أيقونة ملوّنة صغيرة لكل خيار داخل بطاقة بيضاء — لا تدرّجات صاخبة.
- **لون أساسي واحد** + رماديات محايدة + ألوان حالة هادئة.
- **وصول:** تباين واضح، خطوط واضحة، أهداف لمس مريحة.

## الألوان

| الرمز | الاستخدام |
|------|-----------|
| `ghars` (أرجواني «سمو» 50→900) | اللون الأساسي: الأزرار، العناوين الداكنة، التمييز |
| `line` (#e9e6ef) | حدود البطاقات والمدخلات |
| نصوص | رمادي محايد (slate) للنصوص الثانوية، `ghars-900` للعناوين |
| `joy/sky/bloom/grape/leaf` | لمسات مرحة من نقاط شجرة سمو (برتقالي · فيروزي · وردي · أرجواني · أخضر) |

اللون الأساسي مستوحى من شعار **جمعية سمو لتعزيز القيم** (شجرة أرجوانية بنقاط ملوّنة).
الخلفية العامة: أبيض مائل للأرجواني `#f8f7fb`.

## الخطوط

- **IBM Plex Sans Arabic** (للعناوين والنصوص) — خط عربي حديث واضح بإحساس رسمي.
- احتياطي: Tajawal. يُحمَّل عبر `@import` (لا يعطّل البناء دون شبكة).

## الزوايا والظلال

- زوايا معتدلة: `rounded-xl` (12px) للأزرار/المدخلات، `rounded-2xl` (16px) للبطاقات.
- ظلال: `shadow-card` خفيفة جدًا (حدّ + ظلّ بسيط)، `shadow-soft` للعناصر البارزة.

## أصناف المكوّنات (في `globals.css`)

`.card` (بيضاء بحدّ رقيق) · `.btn` / `.btn-primary` (مصمت) / `.btn-ghost` (أبيض بحدّ) ·
`.input` · `.label` · `.chip` · `.stat` · `.page-title` · `.progress` (بلون واحد).

## مكوّنات React (في `components/ui/`)

`Logo` · `PageHeader` (أيقونة + عنوان + رجوع) · `StatTile` · `Chip` · `ProgressBar` ·
`LevelBadge` · `Mascot` (يُستخدم في تجربة الطفل فقط للدفء).

## ملاحظة

تجربة **الطفل** تحتفظ بلمسة دفء (أيقونات، تمييز صناديق المكافآت بثلاثة تصاميم) ضمن
الإطار النظيف نفسه؛ بينما واجهات **ولي الأمر والإدارة** أكثر رسمية وهدوءًا.
