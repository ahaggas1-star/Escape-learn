# نظام التصميم — قِيَم

هوية **فرائحية مرحة موجّهة للطفل** (المستفيد الأساسي)، مع توازن يحترم جدّية ولي الأمر.
المرجع التقني: `apps/web/tailwind.config.ts` و`apps/web/app/globals.css`.

## المبادئ

- بسيطة · أسرية · غير مزدحمة · تحفّز دون ضغط (من `PRODUCT_REQUIREMENTS.md`).
- مرحة وآمنة: ألوان مبهجة، حواف دائرية كبيرة، رموز/إيموجي ودودة، حركات خفيفة.
- القيمة قبل النقاط: التصميم يبرز السلوك والقيمة لا مجرد الأرقام.

## الألوان (Tokens)

| الرمز | الاستخدام |
|------|-----------|
| `ghars` (أخضر) | اللون الأساسي — النمو والغرس، الأزرار الرئيسية |
| `joy` (كهرماني) | الاحتفال، XP، المكافآت |
| `sky` (أزرق) | معلومات/هدوء (المراجعة) |
| `bloom` (وردي) | الشارات/الإنجازات، الإدارة |
| `grape` (بنفسجي) | التقارير/المستويات |

كل لون بتدرّجات 50→900 (الأساسية 600). الخلفية تدرّج ناعم + بقع لونية خفيفة.

## الخطوط

- **العناوين** (`font-display`): `Baloo Bhaijaan 2` — خط عربي مرح مستدير.
- **النصوص** (`font-sans`): `Tajawal` — واضح وعصري.
- تُحمَّل عبر `@import` في `globals.css` (لا تعطّل البناء دون شبكة).

## الزوايا والظلال والحركة

- زوايا: `rounded-2xl`/`3xl`/`4xl` (مظهر ودود).
- ظلال: `shadow-card` (ناعم)، `shadow-soft` (أعمق للأزرار/الأبطال).
- حركات: `animate-float` (التميمة)، `animate-pop`، `animate-wiggle` (خفيفة، غير مزعجة).

## أصناف المكوّنات (في `globals.css`)

`.card` · `.btn` / `.btn-primary` / `.btn-ghost` / `.btn-joy` · `.input` · `.label` ·
`.chip` · `.stat` / `.stat-value` / `.stat-label` · `.page-title` · `.progress` / `.progress-fill`.

## مكوّنات React (في `components/ui/`)

| المكوّن | الوصف |
|--------|-------|
| `Mascot` | تميمة الغرسة 🌱 تطفو بلطف |
| `ProgressBar` | شريط تقدّم بتدرّج لوني |
| `StatTile` | بطاقة مؤشّر بلون اختياري + أيقونة |
| `Chip` | رقاقة ملوّنة (نغمات: ghars/joy/sky/bloom/grape) |
| `LevelBadge` | شعار المستوى برمز نباتي (بذرة🌰→غرسة🌱→نبتة🪴→شجرة🌳→مثمر🍎→قدوة🌟) |

## التطبيق

طُبّق النظام على: تسجيل الدخول (بطل + تميمة)، لوحة ولي الأمر (ترويسة متدرّجة +
بطاقات إجراءات ملوّنة)، لوحة الابن (شعار المستوى + شريط تقدّم + رقاقات)، الترتيب
(بطاقة موضع متدرّجة)، التقارير (بطاقات مؤشّرات). بقية الشاشات ترث الأصناف المحدّثة.
