# apps/web — تطبيق ولي الأمر والابن

تطبيق Next.js + TypeScript يقدّم تجربتي **ولي الأمر** و**الابن** (دخول تابع).

> **الحالة:** المراحل 3–5 منفّذة (ولي الأمر + الابن + الاعتماد + التلعيب الآمن).

## المسارات المنفّذة ✅

- `/login` — دخول/تسجيل ولي الأمر (Supabase Auth)
- `/onboarding` — إنشاء الأسرة وإضافة أول ابن
- `/dashboard` — لوحة ولي الأمر (الأبناء + إجراءات سريعة)
- `/children/new` — إضافة ابن
- `/children/[childId]` — لوحة الابن: XP، المستوى وشريط التقدم، الشارات، الإنجازات، صناديق المكافآت، تنفيذ المهام
- `/values` — اختيار القيمة (الأربع)
- `/values/[valueId]` — أهداف جاهزة + إنشاء هدف خاص (بشرط قابلية القياس)
- `/goals/[goalId]` — إسناد المهام ومتابعة حالتها
- `/review` — مراجعة واعتماد إنجازات الأبناء (+ XP أساسي/إضافي)

## التلعيب الآمن (المرحلة 5)

- منح الشارات تلقائيًا عند تحقق شرط واضح (عدد مهام معتمدة لقيمة/قيمة فرعية).
- الإنجازات التلقائية: أول مهمة، أول هدف مكتمل، 5 أيام متتالية.
- صناديق المكافآت: تُمنح بعد إنجاز حقيقي فقط، فتحها تدويري شفّاف (بلا عشوائية/مقامرة/دفع).
- المنطق في `lib/gamification-engine.ts`، ويُستدعى بعد كل منح XP.

## المسارات القادمة

- التقارير (الابن/الأسرة/إداري) — المرحلة 6

## التشغيل

```bash
cd apps/web
cp .env.example .env.local   # املأ مفاتيح Supabase
npm install
npm run dev
```

قبل التشغيل: طبّق `supabase/migrations/*.sql` ثم `supabase/seed/*.sql` على مشروع Supabase.

التقنية: Next.js 14 · TypeScript · Tailwind CSS · ‎@supabase/ssr · دعم RTL (عربي أولًا).
