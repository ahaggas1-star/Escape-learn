# apps/web — تطبيق ولي الأمر والابن

تطبيق Next.js + TypeScript يقدّم تجربتي **ولي الأمر** و**الابن** (دخول تابع).

> **الحالة:** Placeholder — يُبنى في المرحلة 3 (تجربة ولي الأمر) والمرحلة 4 (تجربة الابن).

## المسارات المخططة (مبدئي)

- `/auth` — دخول/تسجيل ولي الأمر (Supabase Auth)
- `/onboarding` — إنشاء الأسرة وإضافة الأبناء
- `/values` — اختيار القيمة (الأربع)
- `/goals` — اختيار هدف جاهز / إنشاء هدف خاص
- `/tasks` — إسناد ومتابعة المهام
- `/review` — اعتماد ولي الأمر
- `/child/:id` — لوحة الابن (المهام، XP، المستوى، الشارات، الصندوق)
- `/reports` — تقارير الابن والأسرة

التقنية: Next.js · TypeScript · Tailwind CSS · Supabase JS Client · دعم RTL (عربي أولًا).
