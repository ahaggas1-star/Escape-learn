## المسؤوليات المخططة
- حساب إجمالي XP من سجل الأحداث (`xp_events`)
- تحديد المستوى الحالي والتقدم نحو التالي (`levels`)
- تقييم شروط منح الشارات (`badges`)
- تقييم شروط الإنجازات (`achievements`)
- تقييم شروط فتح صناديق المكافآت (`reward_boxes`)

## مبادئ ثابتة
- XP يُحسب من سجل الأحداث، لا من رقم إجمالي مخزّن فقط.
- كل منح (شارة/إنجاز/صندوق) مرتبط بشرط واضح وإنجاز حقيقي.
- لا عشوائية ضارة، لا مقامرة، لا دفع، لا مقارنة جارحة.
